## CLI

```text
anedonia                  abre a tui de hoje
anedonia done "nome"      registra atividade
anedonia add "nome"       adiciona atividade
anedonia start "nome"     inicia tempo ao vivo
anedonia stop             finaliza tempo ativo
anedonia undo             desfaz ultimo registro
anedonia delete           apaga todos os dados
anedonia log              mostra historico
anedonia log compact      historico compacto
anedonia help             mostra esta ajuda
```

## TUI

`a` nova · `t` tempo · `u` desfazer · `h` historico · `q` sair

`Enter` finalizar · `d` descartar
